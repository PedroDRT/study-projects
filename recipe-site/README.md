# Recipe Site — Cupcake de Café com Chantilly

Página web estática de receita, desenvolvida como projeto de prática de **HTML** e **CSS**. A página apresenta a receita de *Cupcake de café com chantilly* com recheio de brigadeiro de café, exibindo informações de tempo, rendimento, ingredientes e modo de preparo.

O layout foi baseado em um design do Figma: [Página de receita — Community](https://www.figma.com/design/FJS8FfMeTysBM0FbVU53qx/P%C3%A1gina-de-receita--Community-?m=auto&t=zr5Aq9x1yyI4G0sn-6)

---

## Tecnologias

- HTML5
- CSS3 (Google Fonts — Alice, background image, border-radius, flexbox-ready layout)

---

## Estrutura do projeto

```
recipe-site/
├── index.html        # Estrutura da página
├── style.css         # Estilos e layout
└── assets/
    ├── main-image.jpg    # Foto principal da receita
    └── bg-image.jpg      # Imagem de fundo da página
```

---

## Seções da página

| Seção | Conteúdo |
|---|---|
| **Sobre a receita** | Descrição, tempo de preparo (1h10), rendimento (12 porções) e dificuldade (Fácil) |
| **Ingredientes** | Lista completa, incluindo massa, brigadeiro de café e chantilly |
| **Modo de preparo** | Passo a passo: massa, recheio e montagem final |

---

## Como visualizar

Nenhuma instalação necessária. Basta abrir o arquivo `index.html` diretamente no navegador:

- **Windows / Mac:** duplo clique no arquivo
- **VS Code:** extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) → botão *Go Live*
